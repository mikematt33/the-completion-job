Getting your list from Steam

  1. Get a Steam Web API key. Any Steam account can create one at steamcommunity.com/dev/apikey. Use any domain name; it is not checked.
  2. Find your SteamID64. It is the 17-digit number in your profile URL, or shown under Edit Profile. Your game details must be public for the next step to work.
  3. Open this address in your browser, with your key and ID filled in, and save the page as a .json file: https://api.steampowered.com/ISteamUserStats/GetPlayerAchievements/v1/?appid=218620&l=english&key=YOUR_KEY&steamid=YOUR_ID
  4. Import that file on the left. The l=english part matters: without it Steam leaves out the names and descriptions the planner needs.

Keep your API key to yourself. This site never asks for it and has nowhere to put it. You can delete the key afterwards from the same Steam page.

Building the file by hand instead

Any JSON file with an achievements array works. Each entry needs name, description, and status (locked or unlocked). If you include counts, its locked number must match the file.

How the planner works

Everything happens in your browser, from the text of the achievements themselves. Nothing is sent anywhere.

Reading each achievement
The description is scanned for the heist name, the difficulty and whether it says "or above", stealth or loud wording, the day of a multi-day heist, time limits, loadout restrictions ("using only", "without using"), and crew wording.
Splitting runs
Targets on the same heist are grouped, then split so a stealth target never shares a run with a loud one, and different days stay separate. Each run says which difficulty covers every target in it.
Fitting your session
Each target gets a rough time estimate from its type and conditions. Targets that share a run only add a few minutes each. Runs are added until your session length or batch size is used up.
Keeping it varied
With variety on, a session starts with one or two quick objectives, puts the biggest heist cluster next, adds at most one hard challenge, then fills with other heists. Infamy breaks go at the end.
What it cannot know
Whether two targets on the same heist can be earned in the same run, whether a solo mod covers a crew achievement, or how long a run will take you. Treat the briefing as a checklist.

Import your checklist

Choose a Completion Job backup, a Steam Web API GetPlayerAchievements export (requested with l=english), or any JSON file with an achievements array of names, descriptions and locked/unlocked status.

Saved HTML can contain only part of Steam’s scrolling list. This importer uses structured JSON and checks the reported totals.

Importing an achievement list starts a new checklist. Export your current backup first. Restoring a backup replaces this browser’s saved state.
